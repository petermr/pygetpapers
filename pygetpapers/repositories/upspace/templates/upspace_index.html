SDG Classifications

This repository supports Sustainable Development Goal (SDG) classifications. Articles are tagged with relevant SDGs to help identify research contributions to global sustainability goals.

Available SDGs: SDG-02 (Zero Hunger), SDG-03 (Good Health), SDG-04 (Quality Education), SDG-10 (Reduced Inequalities), SDG-11 (Sustainable Cities), SDG-13 (Climate Action), SDG-15 (Life on Land), SDG-16 (Peace & Justice)

File Structure

Downloaded articles are organized in the following structure:

  • Article ID/ - Directory named using Handle URL or DOI
  • fulltext.pdf - Downloaded PDF file (if available)
  • metadata.json - Complete article metadata in JSON format
